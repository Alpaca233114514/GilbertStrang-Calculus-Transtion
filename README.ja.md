# Gilbert Strang『Calculus』中国語訳

[English](README.md) | [简体中文](README.zh-CN.md) | 日本語

Gilbert Strang 著 *Calculus*（第3版）の簡体字中国語訳です。MIT OpenCourseWare が提供する英語版 PDF を基に、微積分の学習・自習向けに作成しています。

## 読み始める

- **[中国語読書版 PDF](output/pdf/微积分_中文完整阅读版.pdf)**：879ページ、章のしおり付き。
- [節ごとの Markdown 訳稿](translation_draft/)：読書、対照、修正に利用できます。
- [統合 Markdown 訳稿](deliveries/微积分中文初译-完整PDF-20261025-140448/微积分中文初译_全稿.md)。
- [英語原書 PDF](mitres_18_001_f17_full_book.pdf) · [MIT OCW 教科書ページ](https://ocw.mit.edu/courses/res-18-001-calculus-fall-2023/pages/open-textbook/)。

PDF をダウンロードし、しおりに対応したリーダーで開くことをお勧めします。

## 内容と現状

微分、積分とその応用、極座標と複素数、無限級数、ベクトルと行列、曲線に沿った運動、偏微分、重積分、ベクトル解析を扱い、序文、目次、公式集、索引も含みます。

訳稿は、このリポジトリにある英語原本ファイルの全706ページを対象としています。そのファイルの第16章には導入部しかなく、本文で言及される第16.1～16.3節は含まれていません。訳稿は提供された原本ファイルの内容に従っています。

翻訳と組版には AI を活用しています。原書の演習、数式、図版を残し、原文の一部の印刷上の問題には訳注を付けています。初訳は完了していますが、節ごとの独立した再確認はまだ完了していません。具体的な誤りの報告を歓迎します。中国語 PDF のページ番号は英語原書と異なります。
