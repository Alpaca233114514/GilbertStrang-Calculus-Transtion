## 5.4 不定积分与换元法

<!-- PDF 262 / 印刷页 249 -->

本节用较简便的方法积分，也就是寻找原函数。暂时把矩形面积和及其在 $\Delta x\to0$ 时的极限放在一旁，直接寻找具有指定导数 $v(x)$ 的函数 $f(x)$。在实际计算中，这种方法与求和法大体独立，却给出相同的结果。不过，寻找原函数未必总能成功。若找不到 $f$ 的合适表达式，就回到矩形求和，或者使用第5.8节更好的数值方法。

计算机可以计算 $v$ 的积分，但数值积分通常不靠发现 $f$ 的表达式，而是在指定上下限之间计算一个数，即定积分。这里希望找到一个函数，即不定积分所描述的原函数。这需要 MACSYMA、Mathematica、MAPLE 等符号积分系统，或者形式比较合适的 $v(x)$，或者二者兼具。与一串数值相比，$f(x)$ 的表达式可能有很大优势。

因此，目标是找到原函数并加以使用。第7章将继续发展这些方法；本节虽短，却很有用。先写出已知公式。每一行的 $f(x)$ 都是 $v(x)$ 的原函数，因为 $df/dx=v(x)$。

| 类型 | 函数 $v(x)$ | 原函数的一般形式 $f(x)$ |
|---|---|---|
| 幂函数 | $x^n$ | $x^{n+1}/(n+1)+C$，$n\ne-1$ |
| 三角函数 | $\cos x$ | $\sin x+C$ |
| 三角函数 | $\sin x$ | $-\cos x+C$ |
| 三角函数 | $\sec^2x$ | $\tan x+C$ |
| 三角函数 | $\csc^2x$ | $-\cot x+C$ |
| 三角函数 | $\sec x\tan x$ | $\sec x+C$ |
| 三角函数 | $\csc x\cot x$ | $-\csc x+C$ |
| 反三角函数 | $1/\sqrt{1-x^2}$ | $\arcsin x+C$ |
| 反三角函数 | $1/(1+x^2)$ | $\arctan x+C$ |
| 反三角函数 | $1/(|x|\sqrt{x^2-1})$ | $\operatorname{arcsec}x+C$ |

幂函数公式不含 $n=-1$，因为此时分母 $n+1=0$。$v=x^{-1}$ 将把我们引向 $f=\ln x$，这里先取 $x>0$。

每个积分公式都直接来自求导公式。余弦函数的一个原函数是正弦函数，因为正弦的导数是余弦。为强调这一点，把三个导数与相应积分并列写出：

$$\frac{d}{dx}(\text{常数})=0,\qquad \int0\,dx=C;$$
$$\frac{d}{dx}x=1,\qquad \int1\,dx=x+C;$$
$$\frac{d}{dx}\left(\frac{x^{n+1}}{n+1}\right)=x^n,\qquad
\int x^n\,dx=\frac{x^{n+1}}{n+1}+C.$$

扩充这份表有两种办法。一是对新的 $f(x)$ 求导，把 $f$ 放在一列，把 $v=df/dx$ 放在另一列。二是利用求导法则推导积分法则，这可以很容易地大幅扩充积分表。

*原书脚注：我们很快会遇到 $e^x$，它可以同时放入两列，因为它既是 $f(x)$，也是 $v(x)$。*

### 积分法则

求导法则中最重要的三条，是线性法则、乘积法则与链式法则。其他方法都由它们发展而来。反方向从 $v$ 求 $f$ 时，情况仍然如此：

| 求导法则 | 相应的积分方法 |
|---|---|
| 导数的线性性质 | 积分的线性性质 |
| 乘积求导法则 | 分部积分法 |
| 链式求导法则 | 换元积分法 |

先讨论最简单的线性性质。分部积分留到第7.1节。本节开始介绍换元法，即逆用链式法则，把积分化简。

### 积分的线性性质

$v(x)+w(x)$ 的积分是什么？把二者分别积分，再相加即可。从非负函数的几何图像看，$v+w$ 下方可分为 $v$ 下方的区域，以及 $v$ 到 $v+w$ 之间的区域。面积相加给出和法则。设 $f$、$g$ 分别是 $v$、$w$ 的原函数：

- 和法则：$f+g$ 是 $v+w$ 的一个原函数。
- 常数倍法则：$cf$ 是 $cv$ 的一个原函数。
- 线性性质：$af+bg$ 是 $av+bw$ 的一个原函数。

这有些重复，因为前两条都是第三条的特例；逻辑上只需最后一条。不过，迅速处理常数非常重要，只需把它“提到积分号外”，所以单独列出 $cv\leftrightarrow cf$。证明来自导数的线性性质：$(af+bg)'=af'+bg'=av+bw$。

用积分号写为

$$\int[v(x)+w(x)]\,dx=\int v(x)\,dx+\int w(x)\,dx;$$
$$\int cv(x)\,dx=c\int v(x)\,dx;$$
$$\int[av(x)+bw(x)]\,dx=a\int v(x)\,dx+b\int w(x)\,dx.$$

**关于 $f(x)+C$ 中的常数** 每个原函数都允许再加常数。对组合 $av(x)+bw(x)$，原函数的一般形式为 $af(x)+bg(x)+C$，各部分的常数可合并为一个常数。要表示某函数的全部原函数，只需在找到一个之后加上“$+C$”。真正的问题是找到那一个原函数。

**例1** $v=x^2+x^{-2}$ 的原函数为
$$f=\frac{x^3}3+\frac{x^{-1}}{-1}+C=\frac{x^3}3-\frac1x+C.$$

**例2** $6\cos t+7\sin t$ 的原函数为 $6\sin t-7\cos t+C$。

**例3** 将 $1/(1+\sin x)$ 改写为
$$\frac{1-\sin x}{1-\sin^2x}=\frac{1-\sin x}{\cos^2x}
=\sec^2x-\sec x\tan x.$$
于是一个原函数为 $\tan x-\sec x+C$。这种代数变形可以由符号计算程序完成，也可以自己完成。求导往往比较简单，所以通常应检验 $df/dx=v(x)$。本例的原式符号存在原书笔误，详见译注。

**问题** 怎样积分 $\tan^2x$？

**方法** 将其写成 $\sec^2x-1$。答案是 $\tan x-x+C$。

### 换元积分法

现在介绍本节最有用的方法：换元法。理解其思想，先回顾链式法则：

$$\frac{d}{dx}f(g(x))=f'(g(x))g'(x);$$
$$\frac{d}{dx}\sin(x^2)=\cos(x^2)\cdot2x;$$
$$\frac{d}{dx}(x^3+1)^5=5(x^3+1)^4\cdot3x^2.$$

如果给定右边的函数，左边被求导的函数就是它的一个原函数！有两点需要立即强调。

**1. 常数因子可以调整。** 分别除以2或15，就得到

$$\int x\cos(x^2)\,dx=\frac12\sin(x^2)+C;$$
$$\int x^2(x^3+1)^4\,dx=\frac1{15}(x^3+1)^5+C.$$

注意：2来自 $x^2$ 的求导，5来自五次幂，3来自 $x^3$ 的求导。

**2. 选定内层函数 $g$，也就是 $u$ 后，就必须顾及它的导数。**

| 积分 | 直接作 $g=x^2$ 代换的情况 |
|---|---|
| $\int2x\cos(x^2)\,dx$ | 得 $\sin(x^2)+C$，因为 $g'=2x$ 恰好存在 |
| $\int\cos(x^2)\,dx$ | 不能这样直接套用，缺少 $g'$ |
| $\int x^2\cos(x^2)\,dx$ | 不能这样直接套用，所带因子不是 $g'$ |

把 $x^2$ 换成 $g$ 时，需要其导数。诀窍是识别一个内层函数，使其导数也出现在被积式中。2或15这样的常数可以补齐，但除此之外，$dg/dx$ 必须匹配。内层函数通常记为 $u$。若 $f'=v$，换元法则为

$$\int v(u(x))\frac{du}{dx}\,dx=f(u(x))+C.\tag{1}$$

**例4** 取 $u=\sin x$：
$$\int\sin x\cos x\,dx=\frac12\sin^2x+C.$$
与例6比较。

**例5** 取 $u=\sin x$：
$$\int\sin^2x\cos x\,dx=\frac13\sin^3x+C.$$

**例6** 取 $u=\cos x$：
$$\int\cos x\sin x\,dx=-\frac12\cos^2x+C.$$
与例4比较。

**例7** 取 $u=\tan x$：
$$\int\tan^4x\sec^2x\,dx=\frac15\tan^5x+C.$$

下例取 $u=x^2-1$，$du/dx=2x$。关键一步是选定 $u$。

**例8**
$$\int\frac{x}{\sqrt{x^2-1}}\,dx=\sqrt{x^2-1}+C;$$
$$\int x\sqrt{x^2-1}\,dx=\frac13(x^2-1)^{3/2}+C.$$

把 $x$ 平移为 $x+2$，或者按比例变成 $2x$，尤其容易。

**例9—10**
$$\int(x+2)^3\,dx=\frac14(x+2)^4+C;$$
$$\int\cos2x\,dx=\frac12\sin2x+C.$$

不久你就会对这些计算非常熟悉。严格说，$(x+2)^4$ 的导数用到了链式法则，但内层函数 $u=x+2$ 的导数为1，这个因子自动存在，图像只是发生了平移；图5.8b展示了同类的平移。

例10的内层函数是 $u=2x$，导数为 $du/dx=2$。

图5.8：分别代入 $u=x+1$、$u=2x$、$u=x^2$。最后一图只含 $du/dx=2x$ 的一半，即因子 $x$。图中 area＝面积；图示选择了相应的起始常数，第一图注明 $f(0)=0$。

积分 $\int\cos2x\,dx$ 中缺少所需因子2，但可以先乘以2，再除以2。检验 $\tfrac12\sin2x$ 的导数时，链式法则给出的2恰好抵消 $1/2$。对任意非零常数，同样有

$$\int v(x+c)\,dx=f(x+c)+C,\qquad
\int v(cx)\,dx=\frac1c f(cx)+C.\tag{2}$$

对于正的 $c$，图像在水平方向压缩 $c$ 倍，相应面积除以 $c$。$3x+7$ 则同时包含缩放与平移。

**例11**
$$\int\cos(3x+7)\,dx=\frac13\sin(3x+7)+C;$$
$$\int(3x+7)^2\,dx=\frac13\cdot\frac13(3x+7)^3+C.$$

**关于书写步骤** 换元较复杂时，最好明确写出所需的 $du/dx$。这里 $3x^2+1$ 需要因子 $6x$：

$$\int7x(3x^2+1)^4\,dx
=\frac76\int(3x^2+1)^4\,6x\,dx
=\frac76\int u^4\frac{du}{dx}\,dx.$$

然后积分：

$$\frac76\cdot\frac{u^5}5+C
=\frac76\cdot\frac{(3x^2+1)^5}5+C.\tag{3}$$

最后应检验导数。指数5抵消分母5，链式法则带来的 $6x$ 抵消分母6，剩下起初的因子 $7x$。

**关于微分** 很多人把 $(du/dx)\,dx$ 直接写为 $du$：

$$\int(3x^2+1)^4\,6x\,dx=\int u^4\,du=\frac15u^5+C.\tag{4}$$

这更直接地显示了换元怎样进行。**从 $x$ 换到 $u$ 的同时，也必须从 $dx$ 换到 $du$。**最常见的错误，是混淆 $dx$ 与 $du$。链式法则中的因子 $du/dx$ 绝不可缺少，有了它才能得到 $du$。换元后得到一个容易计算的积分，再把 $u$ 换回 $3x^2+1$。步骤如下：

1. 选择 $u(x)$，计算 $du/dx$。
2. 把被积式识别或整理为 $v(u)(du/dx)\,dx$，即 $v(u)\,du$。
3. 积分 $\int v(u)\,du$，得到 $f(u)+C$。
4. 把 $u=u(x)$ 代回所得原函数。

**例12** 取 $u=\sqrt{x}$，则

$$\int\frac{\cos\sqrt{x}}{2\sqrt{x}}\,dx
=\int\cos u\,du=\sin u+C=\sin\sqrt{x}+C.$$

依次为：换成 $u$，积分，换回 $x$。

必须恰当选择 $u$，使被积式全部用 $u$ 表示。巧妙的代换能算出一些令人惊喜的积分，但并不是所有原函数都能写成初等函数。$\cos(x^2)$ 和 $1/\sqrt{4-\sin^2x}$ 都没有初等原函数。这些积分仍有明确意义，也会出现在应用中。原书把后一个与椭圆周长联系起来；两者的准确区别见译注。

<!-- PDF 266 / 印刷页 253 -->

这类量可以数值计算到非常高的精度，但有限精度的近似值不等于准确的符号表达式。

习题集中练习换元法，它既需要练习，也值得练习。先给一个错误套用的例子：$\int(x^2+1)^2\,dx$ **不等于** $\tfrac13(x^2+1)^3$，因为缺少因子 $du/dx=2x$，不能直接按 $u=x^2+1$ 套用幂函数积分公式。与之相对，常数 $\pi$ 是可以补齐的：

$$\int\sin\pi x\,dx=\int\sin u\,\frac{du}{\pi}
=-\frac1\pi\cos u+C=-\frac1\pi\cos\pi x+C.$$

### 5.4 习题

#### 阅读填空

换元积分法是 $\underline{\text{a}}$ 法则的逆用。$(\sin x)^3$ 的导数为 $\underline{\text{b}}$，因此 $\underline{\text{c}}$ 的一个原函数为 $\underline{\text{d}}$。计算 $\int(1+\sin x)^2\cos x\,dx$ 时，令 $u=\underline{\text{e}}$，则 $du/dx=\underline{\text{f}}$，所以代入 $du=\underline{\text{g}}$。用 $u$ 表示后，积分为 $\int\underline{\text{h}}=\underline{\text{i}}$，再换回 $x$ 得最终答案。

对 $\int\tan(x+3)\sec^2(x+3)\,dx$ 和 $\int(x^2+1)^{10}x\,dx$，合适的代换分别是 $u=\underline{\text{j}}$、$u=\underline{\text{k}}$，对应的微分为 $du=\underline{\text{l}}$ 和 $du=\underline{\text{m}}$，答案为 $\underline{\text{n}}$ 和 $\underline{\text{o}}$。$v\,dv/dx$ 的一个原函数是 $\underline{\text{p}}$。$\int2x\,dx/(1+x^2)$ 化为 $\int\underline{\text{q}}$，我们还没有学习怎样计算它；$\int dx/(1+x^2)$ 却可立即写为 $\underline{\text{r}}$。

### 译注与数学核对

1. 积分表在相关函数有定义且可导的区间上使用。反正弦行要求 $|x|<1$，反正割行要求 $|x|>1$，并沿用前节选定的反正割分支。对 $1/x$，一般的实原函数写作 $\ln|x|+C$，且不同连通分支上的常数可不同。
2. 不定积分的线性公式按“选取一个原函数后再加任意常数”理解。若系数为零，例如 $c=0$，右侧形式 $0\int v\,dx$ 本身不能表示所有常数，仍须统一补 $+C$；不能机械地把原函数集合当作普通数相乘。
3. 例3原书初始分式写成 $1/(1-\sin x)$，但随后改写及答案全都对应 $1/(1+\sin x)$。为使例题连贯，译文将初始分母改成加号。若保留原初始式，则应以 $1+\sin x$ 有理化，答案为 $\tan x+\sec x+C$。这些三角表示须避开 $\cos x=0$；有些点是表示形式的可去奇点，可以用等价表达式延拓。
4. 印刷页251第一组换元积分把 $\cos(x^2)$ 排成 $\cos(x)^2$，与前后推导及答案不符，译文明确改为 $\cos(x^2)$。式(2)补出积分常数；缩放的几何面积解释限 $c>0$，$c<0$ 时还涉及方向反转。
5. 原书把 $1/\sqrt{4-\sin^2x}$ 的积分直接说成椭圆周长，并不准确。它属于第一类椭圆积分；椭圆弧长通常涉及 $\sqrt{1-k^2\sin^2x}$ 的积分，即第二类椭圆积分。两者都通常无初等原函数，但不能相互替代。不存在初等表达式也不等于无法给出准确的特殊函数定义。
6. 第3题的幂公式须排除 $n=-1$，第4题须排除 $n=1$；这些例外会产生对数。原书未单独标出。第30题平方根覆盖整个 $xy$，不是 $\sqrt{x}\,y$。第34(d)题保留未写 $+C$ 的原命题，作为判断题，不替它预先纠正。
